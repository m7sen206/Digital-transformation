# الملخص التنفيذي للإدارة العليا

## الغرض
تهدف هذه الخطة إلى تشغيل قسم التحول الرقمي كوظيفة إدارية تنفيذية تبني طريقة عمل رقمية منظمة داخل الشركة، وليست خطة لتركيب نظام تقني فقط. التركيز العملي هو وضوح المسؤوليات، جودة البيانات، توحيد الإجراءات، ورفع قدرة الإدارة على اتخاذ القرار بناءً على معلومات دقيقة وفي الوقت المناسب.

الخطة تدعم مشروع Odoo وتحوّله إلى وسيلة ضبط وتشغيل وقياس، لكنها لا تختزل التحول الرقمي في Odoo وحده. وهي مناسبة لقسم جديد؛ لذلك تبدأ بتثبيت الحوكمة والأدوار قبل الأتمتة والتوسع.

## لماذا نحتاج القسم الآن؟
وجود مشروع Odoo دون حوكمة داخلية يعرض الشركة لمخاطر تأخر التشغيل، ضعف البيانات، تضارب المتطلبات، واعتماد المستخدمين على Excel بعد الإطلاق. قسم التحول الرقمي يعمل كـ PMO عملي يربط الإدارة العليا والأقسام ومورد Odoo بمخرجات قابلة للقياس.

## نتائج الستة أشهر
| المحور | النتيجة بنهاية ديسمبر 2026 | معيار قياس مختصر |
|---|---|---|
| الحوكمة | ميثاق، RACI، اجتماعات، تقارير منتظمة | 4 تقارير شهرية على الأقل وقرارات موثقة |
| Odoo | ضبط المتطلبات والتغييرات وUAT وGo/No-Go | لا توجد عيوب حرجة مفتوحة قبل التشغيل |
| البيانات | تنظيف واعتماد البيانات الحرجة | 90% اكتمال للبيانات الحرجة قبل Migration |
| الإجراءات | توثيق 12 إجراء رئيسيًا | اعتماد مالك العملية لكل إجراء |
| التدريب | تدريب Key Users وEnd Users | حضور 85% وقياس استيعاب عملي |
| KPI | لوحات أولية قابلة للقياس | كل KPI له مصدر ومالك وتكرار تحديث |
| الأتمتة | أتمتات منخفضة المخاطر | 2-3 أتمتات بعد استقرار الإجراء |
| 2027 | خطة مبنية على نتائج فعلية | Scorecard وخارطة طريق وميزانية تقديرية |

## رسالة للإدارة
نجاح التحول الرقمي لا يعتمد على تشغيل النظام فقط، بل على ثلاثة قرارات إدارية: إلزام الأقسام بتسمية ملاك بيانات وKey Users، منع العمل خارج القنوات الرسمية، واعتماد أن البيانات والإجراءات مسؤولية الأقسام وليست مسؤولية تقنية فقط.
