# خطة حوكمة وتنظيف البيانات

## قاعدة أساسية
لا يتم رفع أي بيانات إلى Odoo كبيانات تشغيلية إلا بعد اعتماد مالك البيانات في القسم المعني. قسم التحول الرقمي ينسق ويفحص المنهجية، ولا يتحمل صحة البيانات بدل الأقسام.

## مجالات البيانات الحرجة
| المجال | مصدر حالي محتمل | مشاكل متوقعة | قاعدة تنظيف | مالك الاعتماد |
|---|---|---|---|---|
| العملاء | Onyx، Excel، WhatsApp، CRM | تكرار، جوالات ناقصة، رقم ضريبي غير موحد | دمج حسب الرقم الضريبي/الجوال/الاسم | المبيعات وخدمة العملاء |
| المنتجات | كتالوج، Excel، ملفات إنتاج | أسماء متعددة ووصف ناقص | قاموس منتجات وفئات موحدة | الإنتاج والمكتب الفني |
| SKU | المستودعات، الإنتاج | أكواد مكررة ووحدات قياس مختلفة | سياسة SKU وUoM | المستودعات والإنتاج |
| الأسعار | المبيعات، المالية | أسعار قديمة وخصومات غير معتمدة | قائمة سعر بتاريخ سريان وصلاحية خصم | المبيعات والمالية |
| الموردون | المشتريات، المالية | تكرار ونقص مستندات | رقم ضريبي وحساب مورد موحد | المشتريات والمالية |
| المخزون | Onyx، جرد فعلي | فروقات أرصدة ومواقع | جرد فعلي ومطابقة عينة ثم نهائية | المستودعات والمالية |
| الصلاحيات | HR، IT | مستخدمون غير نشطين | مطابقة وظيفة/دور/مدير | HR وIT |
| المالية | Onyx، ملفات مالية | أرصدة افتتاحية غير مطابقة | مطابقة وإقفال مرحلي | المالية |

## خطوات التنفيذ
| الخطوة | الفترة | المخرج | معيار القبول |
|---|---|---|---|
| تسمية الملاك | يوليو | Data Owner/Steward لكل مجال | اعتماد الإدارة |
| استخراج البيانات | يوليو/أغسطس | نسخة خام بتاريخ محدد | حفظ مصدر وتاريخ |
| تنظيف أولي | أغسطس | ملفات منقحة | اكتمال الحقول الإلزامية 90% |
| مراجعة عينة | أغسطس | تقرير جودة | قبول العينة أو إعادة تنظيف |
| اعتماد نهائي | سبتمبر/أكتوبر | توقيع مالك البيانات | لا ملاحظات حرجة |
| رفع تجريبي | قبل Go-Live | Migration Test | مقارنة عينات وأرصدة |
