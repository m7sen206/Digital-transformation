# مخرجات تشغيلية

- ملف Excel التشغيلي `digital_transformation_6_month_plan.xlsx` لا يتم تتبعه داخل git لأنه ملف ثنائي.
- يمكن توليد الملف محليًا بتشغيل:

```bash
python scripts/rebuild_digital_transformation_excel.py
```

- مصدر محتوى Excel هو ملفات الخطة داخل `docs` ومخرجات الإدارة داخل `outputs` عند الحاجة.
